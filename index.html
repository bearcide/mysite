Networking Concepts: IPv6 & SRv6

What is IPv6?

Internet Protocol version 6 (IPv6) is the most recent version of the communications protocol that provides an identification and location system for computers on networks and routes traffic across the Internet. Replacing IPv4, it uses 128-bit addresses, which solves the IP exhaustion problem and allows for a practically infinite number of unique IP addresses. It also provides improved routing, simplified network configuration, and enhanced built-in security features.

What is SRv6?

Segment Routing over IPv6 (SRv6) is a modern network architecture that applies segment routing directly to the IPv6 data plane. Instead of relying on complex overlay protocols like MPLS, SRv6 embeds routing instructions (segments) directly inside the IPv6 packet headers. This enables advanced traffic engineering, network slicing, and simplified network programming by allowing a source node to dictate the exact path and functions a packet should undergo across the network fabric.
